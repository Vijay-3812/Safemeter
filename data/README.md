# Data

- `raw/` — labelled CSV traces recorded with `tools/data_logger/log_serial.py`. File name
  pattern `<label>_<trial>_<timestamp>.csv`, columns
  `t_ms,speed_kmh,ax,ay,az,gx,gy,gz,mag_g,tilt_deg,state,label`.
- `synthetic/` — generated by `tools/analysis/simulate_events.py` (git-ignored). Not measurements.

Labels: `normal`, `pothole`, `speed_breaker`, `braking`, `crash`.

Keep raw files small (≤ 30 s each). Commit the real trials — they are the evidence behind the
accuracy table in `docs/testing-plan.md`.
