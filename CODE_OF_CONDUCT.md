# Community code of conduct

SafeMeter welcomes contributors of every background and experience level. Be respectful, constructive and generous with context. Critique the implementation, not the person.

## Expected behaviour

- Use inclusive language and give credit for others’ work.
- Respect consent, privacy and cultural differences.
- Separate evidence from assumptions, especially when discussing safety results.
- Help newcomers reproduce problems safely.

Harassment, discrimination, threats, sexualised content, doxxing, spam and deliberate unsafe testing are not acceptable in issues, pull requests or other project spaces.

## Reporting and enforcement

Report concerns to the repository maintainer using an existing private channel if available. If none is published, request a private contact through a minimal issue without personal or sensitive details. For vulnerabilities, follow [SECURITY.md](SECURITY.md).

Maintainers may edit or remove harmful content, warn participants, restrict interactions or remove contributors, in proportion to the behaviour and its impact. Reports should be handled with discretion; do not promise confidentiality that a public platform cannot provide. Maintainers are subject to the same standards.
